# StrokeMotion — Feedback beta-testeurs

Ce repo reçoit automatiquement les retours envoyés depuis l'outil Commentaire de
[StrokeMotion](https://github.com/mysteropodes) (une issue = un feedback).
Aucun code source de l'application n'est présent ici.

Les issues sont créées par l'app avec un token limité en écriture aux seules
issues de ce repo — elles ne peuvent pas modifier autre chose.
